# My Calculator

A Python calculator project developed using Git and GitHub with automated testing and CI/CD.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Power
- Square root
- Negative number support
- Input validation
- Division-by-zero handling
- Command-line interface (CLI)
